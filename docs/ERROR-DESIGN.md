# 错误提示设计：每种情况一句人话

> 原则：**不统一成一种说法，而是每种错误都有针对性的提示**。
> 状态码只对机器有意义；用户看到的是 message。
> 用户拍板日期：2026-11-26

---

## 一、设计原则

我上一版说"统一成 code/data/message 包裹 + 统一错误码"，这个说法是错的：
**统一的是结构，不是措辞。** 每种错误必须给出能指导下一步行动的话。

三条要求：

1. **说清发生了什么**：不要"操作失败"，要"会话已结束，不能再答题"
2. **说清该怎么办**：不要只报错，要给下一步动作
3. **不泄露内部实现**：不出现 `LLMError`、堆栈、SQL、文件路径

---

## 二、会话类错误

| 场景 | HTTP | code | message（用户看到的） | 前端动作 |
|---|---|---|---|---|
| 没有 session_id | 404 | 40001 | 找不到这场面试，可能链接不完整 | 返回首页 |
| session_id 格式不对 | 400 | 40002 | 面试编号格式不正确 | 清除本地缓存并刷新 |
| 会话不存在（服务重启/过期） | 404 | 40003 | 这场面试已过期（服务重启后常见），可以重新开始一场 | 提示"重新开始"按钮 |
| 会话已结束还答题 | 409 | 40004 | 这场面试已经结束了，去查看报告吧 | 跳转报告页 |
| 会话不属于当前用户 | 403 | 40005 | 这不是你的面试，无权查看 | 返回自己的历史 |
| 并发送答案（重复提交） | 409 | 40006 | 上一题还在评分中，请稍等 | 按钮禁用 2 秒 |
| 轮次已耗尽 | 409 | 40007 | 已达到本轮最大轮次，面试结束 | 跳转报告页 |

**为什么"会话不存在"要分开两种**：

```
40001 没有 id      → 用户操作问题（链接坏了）
40003 存在但过期   → 服务状态问题（重启了）
```

用户看到的话不一样，能做的事也不一样。合成一个"会话不存在"等于什么都没说。

## 三、输入校验类错误

| 场景 | HTTP | code | message | 前端动作 |
|---|---|---|---|---|
| 答案为空 | 422 | 41001 | 请先输入回答再提交 | focus 输入框 |
| 答案过短（<10 字） | 422 | 41002 | 回答太短了，再多说几句（至少 10 个字） | 高亮字数提示 |
| 答案过长（>5000 字） | 422 | 41003 | 回答太长了（上限 5000 字），可以精简一下 | 显示当前字数 |
| 简历没解析出项目 | 422 | 41004 | 简历里没识别到项目经历，请检查是否包含"项目"段落 | 高亮简历区 |
| 简历文件格式不支持 | 415 | 41005 | 只支持 PDF / DOCX / Markdown / TXT，当前文件是 .jpg | 显示支持格式 |
| 简历文件过大 | 413 | 41006 | 文件超过 10MB，请压缩后再传 | — |
| 岗位方向不存在 | 400 | 41007 | 岗位"xx"不存在，可选：ai_algo / backend / frontend / agent_app / general | 重置下拉框 |
| 轮次参数超出范围 | 400 | 41008 | 轮次需在 6–30 之间，当前是 50 | input 加 min/max |
| 面试官风格不存在 | 400 | 41009 | 风格"xx"不存在，可选：balanced / strict / warm / academic / engineering / efficient | 重置下拉框 |

**注意 41007**：这不是"参数错误"，而是**把可选值列出来**。用户看到就知道怎么改。

## 四、鉴权类错误

| 场景 | HTTP | code | message | 前端动作 |
|---|---|---|---|---|
| 未登录访问受保护接口 | 401 | 42001 | 请先登录 | 跳登录页，记住来路 |
| 用户名或密码错误 | 401 | 42002 | 用户名或密码不对 | 清空密码框 |
| 账号已被锁定（连续失败） | 423 | 42003 | 密码错误次数太多，15 分钟后再试 | 禁用表单并倒计时 |
| access token 过期 | 401 | 42004 | 登录已过期，正在自动续期… | **静默 refresh**，用户无感 |
| refresh token 也过期 | 401 | 42005 | 登录状态失效，请重新登录 | 跳登录页 |
| token 被篡改 | 401 | 42006 | 登录凭证无效，请重新登录 | 清空 token |
| 无权限（普通用户访问后台） | 403 | 42007 | 这个页面需要管理员权限 | 显示"联系管理员" |
| 操作别人的数据 | 403 | 42008 | 你只能查看自己的面试记录 | 自动过滤为自己的 |
| 注册：用户名已存在 | 409 | 42009 | 用户名"alice"已被占用，换一个试试 | focus 用户名框 |
| 注册：密码太短 | 400 | 42010 | 密码至少 6 位 | 显示强度提示 |
| 注册：用户名格式 | 400 | 42011 | 用户名只能包含字母、数字、下划线（3–20 位） | 实时校验 |
| 自助注册已关闭 | 403 | 42012 | 当前部署已关闭自助注册，请联系管理员开通 | 显示联系方式 |

**42004 的关键**：这是唯一**不该让用户看到**的错误。
前端拦截器收到就自动调 refresh，成功则重发原请求，失败才展示 42005。

## 五、模型与检索类错误

| 场景 | HTTP | code | message | 是否降级 |
|---|---|---|---|---|
| 模型服务不可达 | 503 | 43001 | 模型服务暂时连不上，正在用规则兜底评分 | ✅ 降级继续 |
| 模型返回空内容 | 502 | 43002 | 模型这次没给出内容，已自动重试 | ✅ 内部重试 |
| 模型输出格式不对 | 502 | 43003 | 模型输出格式异常，已用兜底逻辑处理 | ✅ 降级 |
| 模型超时 | 504 | 43004 | 模型响应太慢（超过 60 秒），本题用规则评分 | ✅ 降级 |
| 模型配额用尽 | 429 | 43005 | 模型额度已用完，请联系管理员充值 | ❌ 阻断 |
| 检索服务不可用 | 503 | 43006 | 语义检索暂不可用，已退回关键词匹配 | ✅ 降级 |
| 检索无结果 | 200 | — | **不是错误**，正常返回空列表 | — |
| 向量维度不匹配 | 500 | 43007 | 向量索引需要重建（模型维度变了） | ❌ 阻断 |

**43001–43004 全都不该让面试中断**。这也是降级链的意义：
模型挂了，规则评分还能给出 verdict，报告照样能出，只是标注 `degraded=true`。

## 六、预算类错误

| 场景 | HTTP | code | message | 行为 |
|---|---|---|---|---|
| 达到最大轮次 | 200 | — | 不报错，正常结束，报告里写"已达轮次上限" | 结束 |
| token 超限 | 200 | — | 不报错，降级到 level 1（少调用模型） | 降级 |
| 成本超限 | 200 | — | 不报错，降级到 level 2（纯规则） | 降级 |
| 用户主动超预算 | 402 | 44001 | 本次面试已达成本上限（0.05 元），报告仍会生成 | 结束并出报告 |

预算类**大部分不是错误**，是正常状态转换。只有用户自己设了硬上限才报 402。

## 七、系统类错误

| 场景 | HTTP | code | message | 是否暴露细节 |
|---|---|---|---|---|
| 数据库连接失败 | 503 | 50001 | 数据服务暂时不可用，请稍后重试 | ❌ |
| 数据库写冲突 | 409 | 50002 | 数据正在被修改，请重试 | ❌ |
| 未捕获异常 | 500 | 59999 | 服务出了点问题，已记录（追踪号：abc123） | 只给追踪号 |
| 接口不存在 | 404 | 40400 | 接口 /api/xxx 不存在 | ✅ |
| 请求体不是合法 JSON | 400 | 40000 | 请求格式错误，需要 JSON | ✅ |
| 请求体缺必填字段 | 400 | 40001 | 缺少必填字段：answer | ✅ 列出来 |

**59999 的做法**：给用户一个追踪号，日志里能查到完整堆栈，但用户看不到。
这比"内部错误"有用——报障时能对上。

## 八、几个之前录快照发现的问题，这样修

| 旧行为 | 新行为 |
|---|---|
| `role` 不存在 → 500 `LLMError: 既没有本地模型...` | 400 `岗位"xx"不存在，可选：ai_algo / backend / ...` |
| 无 sid 答题 → 200 `{error: "会话不存在..."}` | 404 `找不到这场面试，可能链接不完整` |
| 空答案 → 200 `{error: "回答为空"}` | 422 `请先输入回答再提交` |
| 密码太短 → 400 `{error: "密码至少 6 位"}` | 400 `密码至少 6 位`（保留，但前端实时校验） |
| 所有错误都在 200 里 | 按语义分 4xx/5xx，前端可统一处理 |

## 九、给前端的统一处理约定

```typescript
// api/client.ts
axios.interceptors.response.use(
  r => r.data.data,                        // 成功：直接给 data
  err => {
    const { code, message } = err.response?.data ?? {}

    // 42004：access 过期 → 静默 refresh，不打扰用户
    if (code === 42004) return refreshAndRetry(err.config)

    // 42xxx 且非 42004：需要重新登录
    if (code >= 42001 && code <= 42009) {
      router.push({ path: '/login', query: { redirect: router.currentRoute.value.fullPath } })
    }

    // 43xxx：降级类，只在 toast 里轻提示，不阻断流程
    if (code >= 43001 && code <= 43006) {
      toast.warning(message, { duration: 3000 })
      return Promise.reject(err)
    }

    // 其余：正常报错
    toast.error(message)
    return Promise.reject(err)
  }
)
```

关键：**前端按 code 段分流**，不需要逐个 if。
`42xxx` 鉴权、`43xxx` 可降级、`44xxx` 预算、`5xxxx` 系统。

## 十、错误码分段规则

| 段 | 含义 | 前端处理 |
|---|---|---|
| 40001–40007 | 会话 | 提示 + 导航 |
| 41001–41009 | 输入校验 | 提示 + 高亮字段 |
| 42xxx | 鉴权 | 跳登录 / 静默刷新 |
| 43xxx | 模型与检索 | 轻提示，多半已降级 |
| 44xxx | 预算 | 提示 + 出报告 |
| 5xxxx | 系统 | 提示追踪号 |

好处：新增错误码不用改前端，落进对应段就自动有正确行为。
