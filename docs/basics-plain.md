# 四个词到底什么意思（零基础版）+ 账号到底是给谁的

## 一、先说那个黑窗口：它为什么必须开着

你双击 `python webui.py` 之后，那个窗口里跑的是一个**程序**。
程序活着 → 网页能打开；窗口一关 → 程序结束 → 网页打不开。

这不是缺陷，是所有"前台程序"的默认行为（跟你在命令行里跑 `ping` 一样，关了就停）。

区别只在于：**谁负责让这个程序一直活着**。

| 说法 | 人话 |
|---|---|
| **前台控制台** | 程序挂在你眼前这个窗口上，窗口就是它的命 |
| **后台进程 + 启动项** | 程序不挂在窗口上，改成开机时自动启动；你在任务管理器里能看到它，但看不见窗口 |
| **Docker 容器** | 有个叫 Docker 的"管家"帮你启动、重启、收集日志；程序装在盒子里，盒子的开关由管家管 |
| **云主机 + systemd** | 你把程序放到一台常年开机的远程电脑上，那台机器自带的"系统管家"（systemd）负责看住它 |

一句话：**这四个说的都是"谁在看着这个程序"**，不是四种不同的程序。

我们这台机器没装 Docker（`where docker` 是空的），所以这轮做的是第 2 种：
`tools/service.py` 用 `DETACHED_PROCESS` 把程序从窗口上摘下来，再写一个启动项让它开机自启。
实测：关掉所有终端后 `python tools/service.py status` 仍然是 `PID 存活 / 200 OK`。

## 二、每个下载的人是不是都有本地数据库？

**是。** 现在是这样：

```
你的电脑： interview_agent\data\users.db      ← 账号
          interview_agent\data\sessions.db    ← 面试记录
          interview_agent\data\secret.key     ← cookie 签名密钥
```

别人下载同一份代码，在他电脑上也会生成他自己的一份。
**两份数据库互不相通**——没有服务器，也就没有"云端账号"。

所以你问得很对：**在这种情况下，账号几乎没意义。**
你注册了 `zhangsan`，换台电脑就登不进去；别人也永远不会看到你的记录。

## 三、那账号到底是给谁的？

三个真实场景，只有第一个和第三个成立：

| 场景 | 账号有用吗 | 为什么 |
|---|---|---|
| 你自己一个人在自己电脑上用 | **没用** | 登录只增加摩擦，保护的是"自己电脑上的自己" |
| 你把服务挂在局域网/公网（`--host 0.0.0.0`） | **有用** | 这时别人能访问，账号是唯一的隔离手段 |
| 多人共用一台机器（实验室电脑、宿舍电脑） | **有用** | 每人的面试记录要分开 |

**所以我把默认行为改了**（这次真的改了，不是解释）：

| 启动方式 | 行为 |
|---|---|
| `python webui.py`（默认监听 127.0.0.1） | **单机模式：不需要登录**，直接进面试；`/api/me` 返回 `local/admin` |
| `python webui.py --host 0.0.0.0` | **自动切换成需要登录**，未登录访问接口返回 401 |
| `--auth on` | 强制登录（局域网共享时用） |
| `--auth off` | 强制关闭鉴权（明确知道自己只在本机用） |

实测（两个模式都跑过）：

```
# 单机
/                → 200
/api/me          → {"user": "local", "role": "admin"}
/login           → 302 → /（不需要登录，就不给你看登录页）

# 对外
/                → 302 → /login
/api/me          → {"error": "未登录", "login": "/login"}
/api/start       → 401
/register        → 200（第一个注册者成为管理员）
```

判断依据是**监听地址**，不是"有没有账号库"——因为账号真正保护的是"别人能不能访问"。

## 四、这一版的取舍（说明白，不粉饰）

1. **单机不使用账号** → 那么单机上的"后台页"也不再需要管理员身份（本机就是管理员）
2. **一旦对外暴露** → 之前建的账号仍然有效；库里没有账号时，第一个注册的人成为管理员
3. **数据库仍然各存各的** → 想要"换电脑还能看到自己的记录"，必须有服务器 + 云端数据库，
   这是另一个量级的工程（要托管、要备份、要隐私条款），本项目没做，也不假装做了

## 五、你现在的操作

```powershell
# 直接打开就行，不需要注册也不需要登录
双击 7-start-background.bat    # 后台启动（无窗口）
浏览器打开 http://127.0.0.1:8770
```

想给朋友试？那才需要账号：

```powershell
python webui.py --host 0.0.0.0 --port 8770
# 然后把你的局域网 IP 发给他，他会先看到登录/注册页
```
