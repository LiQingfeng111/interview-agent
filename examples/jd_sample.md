# Agent 应用开发实习生（示例 JD）

## 岗位职责
1. 参与 LLM Agent 产品的设计与开发，负责工具调用链路的实现与优化
2. 搭建 RAG 检索增强链路，包括切分、召回、重排与效果评测
3. 参与多智能体编排框架的落地，负责上下文管理与记忆压缩
4. 建立离线评估集与回归流程，保障版本迭代质量

## 任职要求
1. 熟悉 Python，了解 FastAPI 等后端框架
2. 熟悉 LangChain / LangGraph 等 Agent 框架者优先
3. 了解向量数据库与检索原理，有 RAG 实践经历
4. 有结构化输出、JSON schema 校验相关经验者优先
5. 具备良好的问题定位能力，能独立排查线上问题
6. 对大模型评测、幻觉缓解有基本认知
